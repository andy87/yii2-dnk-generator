# Regression tests

The suite generates a Yii Advanced application from the real templates and runs
the generated classes against an in-memory SQLite database. No external database
or running web server is required. The fixture `UserSource` supplies the schema
and validation normally generated by Gii in an application.

Requirements: PHP 8.0 or newer, Composer, and `pdo_sqlite` in addition to Yii's
required PHP extensions.

```sh
composer install
composer test
```

Run one regression group with `php tests/run.php entity`.
`DNK_TEST_VENDOR_PATH` can point to an existing Composer vendor directory when
dependencies are installed outside this checkout.

Generated files and published assets are confined to the ignored `tests/runtime/`
directory. Successful runs remove their generated application; failed runs keep
the application and print its path for diagnosis.
